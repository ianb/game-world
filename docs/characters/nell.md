# Nell

Lives in the old town, the cottage. Program: `crates/characters/src/nell.rs`.

## Description

A pensioner, shy, anxious with people she does not know well. Blames herself when things go wrong.

Placeholder, written to get the valley running. Rename and rewrite at will.
